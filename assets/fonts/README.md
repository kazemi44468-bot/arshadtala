# فونت‌های گروه تعاون ملک ایرانیان

فایل‌های فونت مورد استفاده سایت را در همین پوشه قرار دهید.

پیشنهاد نام‌گذاری:
- Shekasteh.woff2 / Shekasteh.woff / Shekasteh.ttf
- IranNastaliq.woff2 / IranNastaliq.woff / IranNastaliq.ttf

پس از قرار دادن فایل‌ها، در CSS با `@font-face` تعریف و برای تیترهای منتخب استفاده خواهند شد.
